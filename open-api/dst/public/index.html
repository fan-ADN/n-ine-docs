カレンダーイベントを作成

カレンダーイベントを作成します。

終日イベントの場合の注意点:

  • isAllDay: trueの場合、startAtの時刻部分は自動的に00:00:00 UTCに正規化されます
  • endAtは無視され、常にnullとして保存されます
Authorizations:
ApiKeyAuth
Request Body schema: application/json
required
miniappId
required
string

ミニアプリID

genreId
required
string

ジャンルID

title
required
string

イベントタイトル

url
string or null

イベントURL

visibleFrom
required
string <date-time>

表示開始日時（ISO 8601形式）

isAllDay
required
boolean

終日イベントかどうか

startAt
required
string <date-time>

イベント開始日時（ISO 8601形式） 終日イベントの場合、時刻部分は自動的に00:00:00 UTCに正規化されます

endAt
string or null <date-time>

イベント終了日時（ISO 8601形式） 終日イベントの場合、この値は無視され、常にnullとして保存されます

Responses

https://api.app.n-ine.com/v1/calendar-events

  • "url": "https://example.com/event",
  • "visibleFrom": "2025-12-01T00:00:00Z",
  • "isAllDay": false,
  • "startAt": "2025-12-25T10:00:00Z",
  • "endAt": "2025-12-25T12:00:00Z"

マルチキャスト配信を作成

LINEマルチキャスト配信を作成します。

重要な制限事項:

  • LINE Messaging API制限により、1回のリクエストで最大5件のメッセージまで送信可能です
  • ブロードキャスト配信でない場合、targetingSettingsは必須です
  • targetingSettings.includeTargetTypeがTAGSの場合、includeTagIdsは必須です
Authorizations:
ApiKeyAuth
Request Body schema: application/json
required
crmAccountId
required
string

CRMアカウントID

isBroadcast
required
boolean

ブロードキャスト配信かどうか

scheduledAt
string or null <date-time>

配信予約日時（ISO 8601形式）

customAggregationUnit
string or null

カスタム集計単位

object or null

ブロードキャスト配信でない場合は必須

includeTagIds
Array of strings

配信対象タグID（includeTargetType='TAGS'の場合は必須）

excludeTagIds
Array of strings

除外対象タグID

required
Array of objects [ 1 .. 5 ] items

配信するメッセージ（最低1件、最大5件）

Responses

https://api.app.n-ine.com/v1/multicasts

Request samples

  • Payload
Content type
application/json
Example
{
  • "crmAccountId": "01HQZW1234567890ABCDEFGHIJ",
  • "isBroadcast": true,
  • "messages": [
    • {
      • "messageType": "TEXT",
      • "messageJson": {
        • "type": "text",
        • "text": "こんにちは！これはブロードキャストメッセージです。"
        }
      }
    ]
}

Response samples

  • 404

    • "createdAt": "2025-12-26T05:30:00.000Z",
    • "updatedAt": "2025-12-26T05:30:00.000Z"
    }
