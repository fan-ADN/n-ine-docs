カレンダーイベントを作成

カレンダーイベントを作成します。

終日イベントの場合の注意点:

  • isAllDay: trueの場合、startAtの時刻部分は自動的に00:00:00 UTCに正規化されます
  • endAtは無視され、常にnullとして保存されます

string or null

required
string <date-time>

表示開始日時（ISO 8601形式）

isAllDay
required
boolean

終日イベントかどうか

required
string <date-time>

イベント開始日時（ISO 8601形式） 終日イベントの場合、時刻部分は自動的に00:00:00 UTCに正規化されます

string or null <date-time>

イベント終了日時（ISO 8601形式） 終日イベントの場合、この値は無視され、常にnullとして保存されます

マルチキャスト配信を作成

LINEマルチキャスト配信を作成します。

重要な制限事項:

  • LINE Messaging API制限により、1回のリクエストで最大5件のメッセージまで送信可能です
  • ブロードキャスト配信でない場合、targetingSettingsは必須です
  • targetingSettings.includeTargetTypeがTAGSの場合、includeTagIdsは必須です
  • LINE連携情報（Messaging API・LINEログインのチャネル）が未登録のCRMアカウントは指定できません（400 LINE account configuration not found）

ApiKeyAuth

required

required
string

CRMアカウントID

required
boolean

string or null <date-time>

customAggregationUnit
string or null

カスタム集計単位

object or null

ブロードキャスト配信でない場合は必須

includeTagIds
Array of strings

配信対象タグID（includeTargetType='TAGS'の場合は必須）

excludeTagIds
Array of strings

除外対象タグID

required
Array of objects [ 1 .. 5 ] items

配信するメッセージ（最低1件、最大5件）

計測リンクを一括取得

計測リンクを一括作成

計測リンク（tracking links）を一括作成します（1リクエストあたり最大100件）。

各リンクはトランザクションで作成され、デフォルトのリダイレクト条件（priority=0）も自動生成されます。 リンクごとに独立して作成されるため、1件の失敗は他の件に影響しません（レスポンスに件別の成否が返ります）。

一意ルール（違反時は400で、messageに重複箇所が返ります）:

  • analyticsTags: eventNameとtagIdの組み合わせはanalyticsTags配列内で一意
  • clickTags: tagIdはclickTags配列内で一意
  • defaultParameters: sourceParameterはdefaultParameters配列内で一意
  • redirectConditions: priorityはredirectConditions配列内で一意（1以上・昇順に評価）
  • redirectConditions[].tags: tagIdは同一redirectConditions要素のtags配列内で一意（要素をまたぐ重複は可）
  • redirectConditions[].parameters: sourceParameterは同一redirectConditions要素のparameters配列内で一意（要素をまたぐ重複は可）
Authorizations:
ApiKeyAuth
Request Body schema: application/json
required
trackingAccountId
required
string non-empty

作成先のtrackingアカウントID（全リンク共通）

required
Array of objects [ 1 .. 100 ] items

作成するリンクの配列（1〜100件）

Responses
